# Kernel branch and change sets

The kernel is the branch `lvdsim` of the fork `giorgiodelmondo/nvc` (checked out in `kernel/nvc`, fetched by `kernel/build/fetch-nvc.sh`).
There are no loose patch files: every change is a commit on that branch. Mainline submissions are prepared in `kernel/upstream/` (one folder
per pull request, plain `git diff` patches without `NEWS.md`, `PR.md`, `VERIFY.md`) and described in `docs/upstream-contribution.md`.

Base: upstream `nickg/nvc` master. Remote `upstream` of `kernel/nvc` is `https://github.com/nickg/nvc.git`.
